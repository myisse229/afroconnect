Fichiers HotSpot pour MikroTik

Modèle fourni

Génère le fichier login.html avec les réglages saisis ci-dessus, puis télécharge le logo AfroConnect. Place les deux fichiers dans le dossier hotspot/ du routeur.

Logo original : extrais « logo-afroconnect.png » du ZIP fourni et place-le à côté de login.html. Guide d’installation

Avant remplacement : sauvegarde le dossier HotSpot actuel et conserve tous les autres fichiers MikroTik. Le tableau des tarifs du modèle est fixe : vérifie les prix, quotas et validités avant installation. Le bouton de récupération de ticket reste à connecter.

Les fichiers ne sont pas encore installés sur le routeur : ce téléchargement prépare les fichiers pour un transfert manuel via WinBox ou WebFig.
